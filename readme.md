# RGT Order Management System

## 📋 프로젝트 개요
**RGT Order Management System**은 패널 UI와 데이터 그리드뷰(DataGridView)를 사용하여 실시간 주문 데이터를 관리하고 통계 대시보드를 제공하는 데스크톱 애플리케이션입니다.  
이 애플리케이션은 주문 데이터 생성을 시뮬레이션하거나 백그라운드 서비스로 실행하여 실시간 데이터 관리를 지원합니다.

---

## 🛠 주요 기능

### 1. 실시간 주문 관리
- 주문 데이터를 패널 형태로 시각적으로 표시.
- 각 테이블 패널에 주문 상태(주문 접수, 주문 처리, 처리 완료)를 실시간으로 반영.
- 신규 주문 시 테이블 패널이 깜빡이는 시각적 효과 제공.

### 2. 통계 대시보드
- **DataGridView**를 활용해 일별/시간대별 주문 데이터를 표시.
- 실시간으로 통계 데이터를 업데이트.
- 날짜와 시간대별 주문량을 구체적으로 보여줌.

### 3. 주문 데이터 시뮬레이션
- `OrderSimulator`를 통해 임의의 주문 데이터를 생성.
- 이벤트 기반 구조로 주문 데이터를 실시간으로 처리.

# RGT Order Management System - 사용자 가이드

## 1. 프로그램 실행
프로그램을 실행하면 기본적으로 다음 화면이 표시됩니다:
- **테이블 패널 화면**: 실시간으로 주문 데이터를 표시하는 테이블 형태의 패널이 보입니다.
- **통계 대시보드 화면**: 주문 데이터의 일별/시간대별 통계를 표시하는 데이터 그리드 뷰(DataGridView)가 보입니다.

---

## 2. 주요 구성 요소와 작동 방식

### 2.1 테이블 패널
- **목적**: 각 테이블의 실시간 주문 상태를 시각적으로 관리.
- **구성 요소**:
  - **테이블 번호**: 패널 상단에 테이블 번호가 표시됩니다 (예: `RGT1`).
  - **주문 내역**: 패널 중앙에는 해당 테이블의 주문 내역이 표시됩니다.
  - **주문 시간**: 패널 하단에는 마지막 주문 시간(시:분:초)이 표시됩니다.
- **상태 변경**:
  - 패널을 클릭하면 테이블의 상태가 다음 순서로 변경됩니다:
    1. **주문 접수** (파란색 배경)
    2. **주문 처리** (주황색 배경)
    3. **처리 완료** (녹색 배경)
  - 처리 완료 상태가 되면 다시 "주문 접수"로 순환합니다.
- **신규 주문 효과**:
  - 신규 주문이 들어오면 해당 테이블의 패널이 **노란색으로 깜빡이며 알림 효과**를 제공합니다.

---

### 2.2 데이터 시뮬레이션
- **주문 데이터 생성**:
  - `OrderSimulator`가 백그라운드에서 일정 간격(기본 6초)으로 임의의 주문 데이터를 생성합니다.
  - 생성된 주문 데이터는 테이블 패널과 통계 대시보드에 실시간으로 반영됩니다.
- **데이터 형식**:
  - 테이블 번호: `RGT1` ~ `RGT8`
  - 주문 내역: 랜덤으로 선택된 1~3개의 버거 메뉴
  - 주문 시간: 현재 시각

---

### 2.3 통계 대시보드
- **목적**: 일별 및 시간대별 주문 데이터를 집계하여 제공.
- **구성 요소**:
  - **DataGridView** (`orderData`):
    - **날짜**: 주문이 발생한 날짜.
    - **시간대**: 주문이 발생한 시간대 (예: `12:00`).
    - **주문 수**: 해당 시간대의 총 주문 수.
- **데이터 업데이트**:
  - 새로운 주문이 들어올 때마다 통계 데이터가 자동으로 업데이트됩니다.
  - 통계는 다음과 같은 순서로 표시됩니다:
    1. 날짜별 시간대 주문 수
    2. 전체 시간대별 주문 수

---

## 3. 사용자 인터랙션

### 3.1 테이블 관리
- **패널 클릭**:
  - 패널을 클릭하면 테이블 상태가 순차적으로 변경됩니다.
  - 상태는 "주문 접수" → "주문 처리" → "처리 완료" 순으로 전환됩니다.

### 3.2 통계 확인
- **DataGridView 확인**:
  - 통계 대시보드에서 각 날짜와 시간대별로 주문 데이터를 확인할 수 있습니다.

### 3.3 프로그램 종료
- 프로그램을 종료하려면 기본 창 오른쪽 상단의 `X` 버튼을 클릭하면 됩니다.

---

## 4. 설치 및 실행

### 4.1 설치
1. 제공된 `RgtSetup.msi` 파일을 실행하여 프로그램을 설치합니다.

### 4.2 실행
1. 설치된 `주문관리시스템`을 실행합니다.
2. 데이터가 실시간으로 표시되며, 프로그램 사용이 가능합니다.

---

## 5. 문제 해결

### 5.1 프로그램 오류
- **"Object reference not set to an instance of an object" 오류 발생 시**:
  1. DataGridView가 올바르게 초기화되었는지 확인합니다.
  2. `Form1` 클래스의 `InitializeOrderDataGrid` 메서드가 호출되었는지 점검합니다.

### 5.2 데이터 업데이트가 멈춘 경우
- **원인**: `OrderSimulator`가 실행되지 않음.
- **해결 방법**:
  - `OrderSimulator`의 `Start` 메서드가 호출되었는지 확인합니다.
  - 타이머 설정(기본 60초)을 다시 점검합니다.
